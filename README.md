# Instytut Beauty Line

Nowa strona Instytutu Beauty Line w Poznaniu.

- `index.html` – gotowa strona (jeden plik, fonty wbudowane).
- `src/index.html` – źródło do edycji.

Po zmianach w źródle: `npm install && python3 build.py`.

Wersja robocza ma `noindex` – usuń tę linię w `src/index.html` po przeniesieniu strony na instytutbeautyline.pl.
